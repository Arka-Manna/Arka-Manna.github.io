18 / EMBEDDED & IoT

WI-FI CLOCK V2

An ESP8266-powered smart LED matrix clock combining real-time internet time, alarms, stopwatch, countdown timer and a browser-based control dashboard.

COMPLETED
ESP8266 MAX7219 NTP WEB DASHBOARD IoT
01 / OVERVIEW

More than a clock. It's a tiny IoT dashboard.

Wi-Fi Clock V2 is an upgraded version of my earlier ESP8266-based clock project.

The project combines an ESP8266, MAX7219 LED matrix and buzzer to create a multi-function smart clock controlled entirely through a web browser.

The system does not require a dedicated mobile application. Once connected to Wi-Fi, the ESP8266 hosts its own web dashboard.

05 / SOFTWARE

The ESP8266 runs the whole system.

The firmware combines display control, Wi-Fi networking, NTP synchronization and a web server into a single embedded application.

Display Stack

  • MD_Parola
  • MD_MAX72xx
  • SPI communication
  • Four MAX7219 display modules

Network Stack

  • ESP8266WiFi
  • ESP8266WebServer
  • WiFiUDP
  • NTPClient
06 / WEB DASHBOARD

A browser becomes the remote control.

The ESP8266 hosts a complete HTML dashboard directly from the device.

Through the dashboard, the user can configure messages, alarms and timers, switch display modes and operate the stopwatch.

07 / TIME SYSTEM

Accurate time without an RTC module.

Instead of relying on a dedicated real-time clock module, the system retrieves time from an NTP server over the internet.

The firmware uses an offset of 19,800 seconds to represent Indian Standard Time (UTC+5:30), with the NTP client refreshing periodically.

08 / TESTING

From prototype to daily-use device.

Testing focused on Wi-Fi connectivity, display operation, NTP synchronization, web-dashboard control, alarm behaviour, stopwatch operation and countdown timing.

09 / RESULT

A smarter second generation.

Wi-Fi Clock V2 evolved the original simple ESP8266 clock into a considerably more capable embedded IoT device.

It combines physical hardware, internet connectivity and a responsive browser interface into a single self-contained system.
