14 / AEROSPACE

MONOCOPTER

An experimental single-rotor aerial platform exploring unconventional flight control, embedded stabilization and custom flight-control hardware.

COMPLETED

01 / OVERVIEW

One rotor. A completely different flight problem.

The Monocopter is an experimental aerial platform based on the single-rotor monocopter concept. Unlike conventional multirotors, the aircraft uses one primary rotor and aerodynamic control surfaces to influence its attitude.

The project combines an unconventional airframe with embedded flight-control electronics, inertial sensing, servo actuation and RC input.

The project is based on the dRehmFlight-Monocopter concept, which uses a single rotor with air vanes for position control. :contentReference[oaicite:1]{index=1}

02 / FLIGHT CONCEPT

Controlling an unstable aircraft.

Flight System

  • Single primary rotor for lift and propulsion.
  • Aerodynamic vanes used for attitude control.
  • Inertial measurements used for stabilization.
  • Servo-controlled flight surfaces.

Control Approach

  • IMU-based attitude estimation.
  • Flight-control loop running on a microcontroller.
  • RC commands supplied by the receiver.
  • Control mixing between pilot input and stabilization.
03 / ELECTRONICS

Building the flight controller.

A major part of the project involved adapting the flight-control architecture to an RP2040-based controller.

The system uses inertial sensing to obtain the aircraft's motion information and converts that information into servo and ESC control outputs.

04 / HARDWARE

System architecture.

Flight Controller Raspberry Pi Pico W / RP2040
IMU MPU9250 inertial measurement unit
Receiver FlySky FS-iA6B
Servo Actuation SG90 micro servos
ESC SimonK 30A ESC
Propulsion BLDC motor with 3S LiPo power system
05 / SOFTWARE

Flight-control software.

The flight-control system is based around the dRehmFlight architecture, with the controller responsible for reading the IMU, estimating aircraft attitude and generating actuator commands.

The project also involved adapting Teensy-oriented flight-control code for the RP2040 platform and working through hardware interface and library compatibility.

dRehmFlight Madgwick Filter MPU9250 RP2040 PWM
06 / TESTING

Test. Tune. Fly.

Development involved testing the inertial measurement system, receiver input, servo outputs and flight-control software individually before integrating the complete system.

07 / RESULT

An unconventional flight platform.

The completed project demonstrates the integration of an unconventional aircraft configuration with embedded flight-control electronics and RC actuation.

The project provided hands-on experience with flight stabilization, inertial sensing, servo control, receiver interfaces and adapting flight-control software to a different microcontroller architecture.
