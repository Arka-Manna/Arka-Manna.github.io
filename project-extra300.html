EXTRA 300

A custom RC aerobatic aircraft project focused on airframe development, control response, aerodynamic behaviour and flight testing.

01 / OVERVIEW

Built for the sky. Tuned for aerobatics.

The Extra 300 is an RC aerobatic aircraft project developed to explore aircraft construction, aerodynamic behaviour and precise radio-controlled flight.

The project involved bringing together the airframe, propulsion system, control surfaces, electronics and radio system into a complete flyable aircraft.

02 / DESIGN

Designed around flight performance.

Airframe

  • Aerobatic aircraft configuration.
  • Lightweight structural construction.
  • Balanced weight distribution.
  • Designed for responsive control.

Flight Performance

  • Responsive control-surface movement.
  • Stable high-control-rate operation.
  • Manual RC flight control.
  • Aerobatic flight capability.
03 / BUILD

From airframe to aircraft.

The aircraft was developed through airframe construction, electronics integration, control surface setup and progressive flight testing.

04 / HARDWARE

Aircraft system.

Aircraft Type RC aerobatic fixed-wing aircraft
Control Radio-controlled flight system
Propulsion Electric brushless propulsion system
Control Surfaces Elevator, rudder and aileron based flight control
Power LiPo-powered electric propulsion
05 / FLIGHT CONTROL

Every input matters.

The aircraft relies on coordinated control of its aerodynamic surfaces to generate pitch, roll and yaw responses.

Flight testing involved evaluating control response, trim, stability and the behaviour of the aircraft during different manoeuvres.

AILERON ELEVATOR RUDDER RC CONTROL
06 / FLIGHT TESTING

Test. Trim. Fly.

Flight testing was used to evaluate the aircraft's stability, control response, trim and overall handling characteristics.

07 / RESULT

A complete flying machine.

The completed Extra 300 project demonstrates practical experience in RC aircraft construction, propulsion integration, control-surface setup and flight testing.

The project also provided hands-on understanding of how airframe design, weight distribution, propulsion and control inputs interact during actual flight.
